### Step 2: Verify Primary Artifact

```python
import pandas as pd

df = pd.read_csv("data/test/jain/canonical/jain_86_novo_parity.csv")

# Check total count
assert len(df) == 86, f"Expected 86 rows, got {len(df)}"

# Check label distribution
n_specific = (df["label"] == 0).sum()
n_nonspecific = (df["label"] == 1).sum()
assert n_specific == 57, f"Expected 57 specific, got {n_specific}"
assert n_nonspecific == 29, f"Expected 29 non-specific, got {n_nonspecific}"

# Check reclassified antibodies
for ab in ["lebrikizumab", "galiximab"]:
    row = df[df["id"] == ab]
    assert len(row) == 1, f"{ab} not found"
    assert row.iloc[0]["label"] == 1, f"{ab} should have label=1"
    print(f"✅ {ab}: label={row.iloc[0]['label']}")

print("✅ Primary artifact verified")
```

## Failure Modes

### Failure: Script exits with error

**Action:** Debug script, return to Phase 1.

### Failure: Wrong label count

**Action:** Check Tier D implementation in script. Ensure no duplicate reclassifications.

### Failure: More than 2 rows changed in diff

**Action:** Investigate. May indicate unintended side effects.

### Failure: VH-only file not generated

**Action:** Check if separate script needed. May need to run additional preprocessing step.
